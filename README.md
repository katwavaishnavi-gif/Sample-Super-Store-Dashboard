# 📊 Superstore Sales Analysis Dashboard (Microsoft Excel)

## 📌 Project Overview

The **Superstore Sales Analysis Dashboard** is an interactive Microsoft Excel project developed using the Sample Superstore dataset. It provides valuable business insights by analyzing sales, profit, customer orders, product categories, and regional performance through Pivot Tables, Pivot Charts, and KPI dashboards.

This project demonstrates how Excel can be used as a powerful Business Intelligence (BI) tool for data analysis and visualization.

---

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify top-performing and low-performing product categories.
- Compare sales across different regions and states.
- Understand customer purchasing trends.
- Create an interactive dashboard for business decision-making.

---

## 📂 Dataset

The project uses the **Sample Superstore** dataset, which contains information such as:

- Order ID
- Order Date
- Ship Date
- Customer Name
- Segment
- Region
- State
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit
- Shipping Mode
